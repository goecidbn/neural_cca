synthetic — Synthetic data generators
=====================================

Overview
--------

The ``synthetic`` subpackage is the single source of truth for the
synthetic spike-train and waveform data used by the example
notebooks and the test fixtures.  It exists to dedupe ~115 lines
of bin-wise Poisson + Gaussian-template setup that used to be
copy-pasted into every example notebook and into
``tests/conftest.py`` — the same idea was implemented three or
four times and drifted out of sync any time someone touched one
copy.

Layering
--------

Notebooks live under ``examples/`` and end-users open them
directly; they cannot reach into ``tests/conftest.py`` because
``tests/`` is not in the installed wheel (the hatch build target
only ships ``neural_cca/``).  Putting the helpers in
``neural_cca.synthetic`` lets notebooks and tests import the same
function from the same location.  ``tests/conftest.py``'s
``make_tuned_spikes`` now re-exports from this module, so seeded
test fixtures continue to produce bit-identical streams (same
``PCG64DXSM`` + ``SeedSequence(42)`` construction).

Scientific scope
----------------

**Bin-wise inhomogeneous Poisson with absolute refractory.**
:func:`poisson_train` draws Bernoulli trials at rate ``rate(b) · dt``
for each time bin ``b``, with a hard refractory window of
``max(1, int(refractory_s / dt))`` bins after every spike.  The
loop is pure Python because the refractory constraint couples
consecutive bins; vectorising would require post-hoc rejection of
violations and would slightly overcount.  Good enough for one-shot
demo construction at 25 kHz × 2.5 s × few-hundred trials.

**Single Gaussian-tuned cluster.**  :func:`make_tuned_spikes`
synthesises spikes from a Gaussian-tuned neuron with parameters
(preferred angle, sigma, peak rate, base rate).  Uses a
per-trial Poisson recipe (``rng.poisson`` count + ``rng.uniform``
times) — distinct from :func:`poisson_train`'s bin-level path so
seeded tests stay stable when the notebook helpers evolve.

**Canonical two-unit demo.**  :func:`make_two_unit_demo` builds the
full two-cluster dataset every example notebook used to construct
inline: one orientation-indifferent unit, one orientation-selective
unit with a Gaussian tuning curve, both generated by
:func:`poisson_train` with a 1 ms absolute refractory, plus
Gaussian-template waveform snippets and a fully-loaded
:class:`SortingData` container.  Returns a :class:`TwoUnitDemo`
``NamedTuple`` whose fields match the variable names the notebooks
expose downstream, so the notebook-cell rewrite is one import +
explicit unpacking and nothing else changes.
